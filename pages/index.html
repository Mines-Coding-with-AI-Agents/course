Students build the machinery behind coding agents, not just use it.

  • An agent from scratch

    A working agent loop written against the raw model API, then ported to the Claude Agent SDK.

    Lectures 20 and 21

  • Tools and an MCP server

    Tools redesigned one change at a time and measured over repeated runs, and a Model Context Protocol server of their own.

    Lectures 10 and 16

  • Retrieval with real metrics

    Retrieval systems scored against a gold set with recall@k, MRR, nDCG, and faithfulness.

    Lectures 12 to 14

  • Evaluation as an experiment

    Benchmarks read for contamination, pass@k reported with error bars, and model graders checked for bias.

    Lectures 22 to 24

  • Evidence-based debugging

    A failing test first, ranked hypotheses, and no fix accepted on the agent's word.

    Lecture 7

  • Attacks on their own systems

    Prompt injection run against their own retrieval pipelines, then guardrails and human approval gates.

    Lecture 26

The course is built with the same tools it teaches.

Its lesson plans, quizzes, slides, and lab checkers are drafted by Claude Code under six reusable skills, checked by separate reviewer agents, and signed off by the instructor. Students work the same way: they open Claude Code inside the course repository to prepare, run their labs, and replay the in-class demos.
