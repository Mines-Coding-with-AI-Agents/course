# Decisions

Why this site is built the way it is, newest decisions at the bottom of each section.

## Audience and purpose

The site is a showcase for the public and industry, and it is the page that the Data Science master's program's LinkedIn post links to.
So the home page has to make sense within about ten seconds to someone arriving from LinkedIn with no context, and every page carries its own share preview (title, description, and a 1200x630 image).
Recruiting copy ("register now", prerequisites, cost) is left out until a next offering is confirmed, because a call to enroll in a course that is not scheduled would be a false claim.

## Built now, before the course has run once

The instructor's July plan deferred a public showcase until the course had run once.
On 2026-09-28 the instructor decided to build it now, mid-semester, so the showcase can support the LinkedIn post.
The site therefore describes the course design and what students build, and it makes no outcome claims until they are true.

## What is published, and what is not

Published: the schedule, module and lecture summaries, learning outcomes, the class format, project descriptions, and the instructor's note on how the course was built.
Not published: anything from the private repositories verbatim, answer keys, quizzes, lesson plans, teaching notes, rubrics, grading internals, and any student's work.
Student work appears only for students or teams who opted in, in writing; the Demo Day section says so and shows nothing until then.
The internal survey of other universities' courses is not published, because its comparisons of named programs came from an agent-run sweep and are not verified; the build note mentions the survey only as a step in the process.

## Stack

Plain HTML and CSS, generated by one standard-library Python script (`build.py`) from two JSON files and four page files.
A static site generator such as Astro or Eleventy would add dependencies to keep updated for a site of four pages; the script has none, runs anywhere Python runs, and matches the plain HTML default that students used for their own Project 1 sites.
`check.py` is the site's test suite, in the same contract as the course's lab checkers: one PASS or FAIL line per fact, and exit code 0 only when every check passes.
GitHub Actions builds, checks, and deploys on every push and once a day, so date-based status lines stay current.

## Address

A project site from the public `course` repository in the `Mines-Coding-with-AI-Agents` organization, served at `https://mines-coding-with-ai-agents.github.io/course/`.
The name matches the organization's other repositories (`development`, `student`).
A custom domain can be added later by changing `site_url` and `base_path` in `content/site.json` and adding the domain in the repository's Pages settings.

## Design

The brief is professional, modern, and minimal.
The first version, styled as a geological survey report with a textured stratigraphic column, was replaced on 2026-09-28 for that reason.

One typeface does all the work: Mona Sans, GitHub's open-source variable font, fitting for a course whose projects all ship on GitHub.
Headings use a slightly wider cut and tight spacing; body text uses the regular width.
The palette is white, navy ink, grays, and one blue accent, and structure comes from white space and hairlines rather than boxes or shadows.
The font is self-hosted under the SIL Open Font License, so the site makes no third-party requests.

The signature element is the semester timeline: the modules as one segmented bar that fills in as the semester passes, the four projects as bars beneath it, and a line at today.
A status line above it names the next lecture, and the daily rebuild keeps both current, so a visitor sees a course that is running, not a brochure.
On phones the chart becomes a list of modules with a progress bar each; the same list serves screen readers on wide screens, where the chart itself is hidden from them.
The only motion is the bar filling once on load, and it is turned off for readers who prefer reduced motion.
The link preview image shows the timeline without a today line, so a cached preview never shows a stale date.

## Not included yet

- Analytics. If the instructor wants to know how many visitors the LinkedIn post brings, GoatCounter or Cloudflare Web Analytics are free and privacy-friendly; either needs an account that only the instructor can create.
- A custom domain.
- The Demo Day gallery, until teams opt in.
